# Security Policy

## Reporting Vulnerabilities

Report security issues privately to t@desplega.sh.

Please include:

- A description of the issue and its impact.
- Steps to reproduce or a proof of concept, if available.
- Any relevant version, platform, or environment details.

Do not disclose vulnerabilities publicly until we have had a chance to review
and coordinate a fix.

## Supported Versions

Security fixes are published in the latest npm version of
`@desplega.ai/claude-bridge`.
